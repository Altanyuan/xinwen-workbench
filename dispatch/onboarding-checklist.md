# 新人入职检查清单

加新人走完「申请、进网、入册、上岗」四步后，逐项打勾。缺一项都不算完。

- [ ] 新号改名完成，工单池里认这个名
- [ ] Tailscale 进网，后台已批，尾网地址已分
- [ ] SSH 密钥是专用的，私钥没离开它自己的机器
- [ ] 指纹对得上，钥匙没重复，authorized_keys 行数对
- [ ] 名册 ROSTER 有一行，状态改成已签到
- [ ] 工位目录已建，额度和状态有地方写
- [ ] 工作台三处都加上了：聊天列表、指挥中心、原理页
- [ ] 头像换成 Jolly，缓存版本号同步升了
- [ ] 聊天轮询只在工作日 09:30–21:00 跑，午休暂停
- [ ] 额度每 30 分钟上报，聊天页额度卡有数
